# Stock Market Simulator

## Description
A stock market simulator focused on buying, selling, and managing investments. This project created to help me learn how real world stock market would look like.

## Features
- Company names and tickers generator
- ...
==**Project still in development, features may change**==

## Prerequisites & Running

- Python 3.13 Installed
- OS : Windows

How to run:

1. **Clone the repository**
   ```bash
   git clone https://github.com/ThatPythonOne/StockMarketSimulator.git
   cd StockMarketSimulator
   ```
3. **Activate the virtual environment**
   - Open terminal in StockMarketSimulator/
   ```bash
   cd .venv/Scripts/
   activate.bat
   ```
2. **Run**
   - Open terminal in StockMarketSimulator/source
   ```bash
   python main.py
   ```
